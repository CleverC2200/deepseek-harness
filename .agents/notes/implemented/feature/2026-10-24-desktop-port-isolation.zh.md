# Agent Note: 桌面实例端口隔离

Status: implemented

[English](2026-10-24-desktop-port-isolation.md) | 中文

## 问题

公司 Desktop 与已安装的上游 Desktop 或其他开发实例可能争用同一固定监听端口。独立 profile 和 Electron userData 不会隔离 TCP 监听器。

## 决策

`DSH-004` 让公司源码的 Desktop Host 使用系统分配端口。安装版和开发实例均使用现有就绪 IPC 返回的实际地址。上游应用保持不变，显式 profile 端口覆盖继续由维护者负责。

## 考虑过的替代方案

**另一个公司固定端口。** 更换共享默认端口仍会让安装版与开发实例互相争用。系统分配端口可以沿用现有地址发现流程实现实例隔离。

## 影响

开发启动器保留独立 home、profile 和 Electron userData。启动器不在绑定前扫描空闲端口、不保留另一个共享固定端口、不终止未知监听进程，也不改写用户配置。现有已安装客户端需要新构建才能采用这项源码改动。

## 验证与退场

启动回归通过真实启动入口同时建立监听器并核对返回的实际地址。真实 Host 子进程验证覆盖旧默认端口被占用时的并发启动和正常关闭。平台打包和安装后窗口验收另行验证。采用的上游实现提供同等实例隔离与地址发现能力后，再删除这项公司差异。
