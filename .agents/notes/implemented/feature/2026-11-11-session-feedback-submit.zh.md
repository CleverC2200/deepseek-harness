# Agent Note: 产品 Session 反馈提交

Status: implemented

[English](2026-11-11-session-feedback-submit.md) | 中文

## 问题

本地 `feedback/record` 事件能确认 Session 备注，却不能确认产品反馈服务已接收对话材料。认证上传及回执归产品负责。

## 决策

`DSH-006` 为 `sessionFeedback` 增加单一产品提交提供者。Core 负责描述校验、Remote 传输与共用弹窗生命周期。提供者负责认证、收集、上传和接收回执。Session 表单调用该操作；带文本的 `/feedback <text>` 与消息评分保留既有日志事件。[共用弹窗决策](2026-09-08-feedback-dialog-and-categories.zh.md)继续负责消息分类与入口。

## 考虑过的替代方案

通过 `feedback/record` 路由产品上传会混合遥测授权与独立认证上传，可能在产品接收前显示成功。产品专属弹窗会重复既有草稿与释放生命周期。

## 影响

没有提供者时，草稿保持打开并提示无法提交。只有提供者成功返回后才显示报告编号及接收时间。产品提供可显示的失败信息；通用传输失败使用 Core 本地化文本。

## 验证与删除条件

提供者、弹窗及组合 Web 测试覆盖服务缺失、描述必填、回执路由及过期结果。采用的上游反馈接口支持同等产品提交及回执语义后，删除此公司差异。
