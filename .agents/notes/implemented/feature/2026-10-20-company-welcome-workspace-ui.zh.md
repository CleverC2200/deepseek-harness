# Agent Note: 公司欢迎区与工作台 UI 扩展接口

Status: implemented

[English](2026-10-20-company-welcome-workspace-ui.md) | 中文

## 问题

现有品牌图标插槽与固定工作区标题无法表达公司欢迎文案和单一可展开的工作台标题。

## 决策

`DSH-002` 将公司欢迎文案和导航样式留在 Workbench。Core 提供空会话欢迎内容插槽，以及可选的工作区标题和展开属性。原输入区、工作区选择、Session 浏览器和持久化仍归 Core。

## 考虑过的替代方案

替换整个会话或工作区浏览器会复制无关行为。DOM 补丁会让插件依赖私有结构。最小公开 UI 输入让插件复用原组件。

## 影响

没有贡献时保留原欢迎区和工作区呈现。收起时保留浏览器挂载状态；原生搜索和目录快捷键请求壳层展开。上游提供等效控制且原行为测试通过后，删除重复的公司接口。

## 验证

所属组件测试覆盖默认欢迎回退、欢迎内容贡献、收起前后的工作区行身份以及快捷键展开请求。配套插件测试覆盖公司文案、导航及组合浏览器行为。源码测试不证明已安装客户端或发布验收。
