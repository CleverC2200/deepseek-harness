# Agent Note: 公司模型来源展示范围

Status: implemented

[English](2026-10-21-company-model-provider-scope.md) | 中文

## 问题

公司客户端同时展示直接接入的 provider 和业务网关发现的模型。显示名不能可靠标识模型来源。

## 决策

`DSH-003` 为两个模型菜单共用的目录增加可选 provider 标识过滤。部署方提供可见标识；Core 管公共菜单，GEA 管公司客户端配置。过滤只改变展示，保留已保存选择、Host 目录和执行授权。

## 考虑过的替代方案

按显示名筛选会误判改名模型。移除 adapter 或重写用户设置会改变执行和保留配置。替换选择器会重复公共选择生命周期。

## 影响

默认展示全部 provider。显式空列表产生空菜单。已删除或被排除的选择保留原持久意图。上游提供等效部署过滤且相同的选择保留测试通过后，移除此公司扩展。

## 验证

目录和双入口测试覆盖准确来源标识、默认值、空列表、刷新、选择与历史意图保留。Host 配置测试覆盖公开注入与释放。源码测试不证明已安装客户端或发布验收通过。
